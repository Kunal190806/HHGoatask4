# TigerGraph Architecture & Schema

TigerGraph serves as the absolute source of truth and Evidence Engine for the agent.

## Schema
- **Vertices**: Customer, Card, Transaction, DeviceProfile, EmailDomain, BillingRegion, ClosedCase
- **Edges**: OWNS, MADE_TXN, FROM_DEVICE, BILLED_IN, USED_EMAIL, NEXT_TXN, CASE_INVOLVES_TXN, CASE_ON_CARD

## Loading Jobs
The `load_tigergraph.py` script maps the pre-processed CSVs into the Graph.
It expects `v_*.csv` and `e_*.csv` files generated by the ingest script.

## GSQL Queries
The queries inside `tigergraph/queries/` are mapped to MCP tools. They represent the Agent's hands and eyes inside the graph database.
